# 돌 맞추기 (stone-clash)

Claude Code 가 작업하는 동안 채팅 옆 패널에서 하는 5속성 돌 맞추기 턴제 퍼즐입니다. Claude Code 의 mod(플러그인)로 동작합니다.

## 설치

터미널에서 연 Claude Code 세션의 프롬프트에 입력합니다.

```
/plugin install stone-clash --marketplace moonjh9392/claude-mod-stone-clash
```

셸에서 설치하려면:

```bash
claude plugin install stone-clash --marketplace moonjh9392/claude-mod-stone-clash
```

마켓플레이스 추가를 묻는 질문에 `y` 로 답하고 설치 범위를 고르면 됩니다. mod 를 지원하는 Claude Code 버전이 필요합니다.

## 실행

- 세션을 시작하면 패널이 열립니다. 터미널 폭이 좁으면 자동으로 열리지 않으니 `/stone-clash` 를 입력하세요.
- 패널은 터미널 세션에서 확인했습니다. 데스크톱 앱 세션에서는 패널이 뜨지 않을 수 있습니다.

## 규칙

- 6×6 판에 5속성 돌(물🔵 불🔴 땅🟤 나무🟢 전기🟡)이 무작위로 깔립니다.
- 돌 하나를 누르고 바로 옆(상하좌우) 돌을 누르면 자리가 바뀝니다. 줄이 맞춰지지 않아도 바꾼 자리는 그대로 남고 턴을 한 번 씁니다. 여러 번 옮겨 큰 줄을 준비했다가 한 번에 터뜨릴 수 있습니다.
- 가로·세로는 3칸 이상, 대각선은 4칸 이상 같은 돌이 이어지면 사라지고 몬스터에게 데미지가 들어갑니다.
- 몬스터는 3~5턴마다 공격합니다. 돌을 한 번 옮길 때마다 공격이 한 턴 가까워집니다.
- 몬스터 체력이 0 이 되면 클리어, 내 체력이 0 이 되면 쓰러집니다. 체력은 스테이지마다 가득 찬 채로 시작합니다.
- 전투 화면 위쪽에 그 몬스터의 약점 속성이 표시됩니다. 약점 돌을 맞추면 데미지가 1.5배입니다.

### 테마와 스테이지

- 테마는 속성별로 5개, 테마마다 스테이지 7개(마지막은 보스)로 기본 35 스테이지입니다.
- 난이도는 물 → 불 → 나무 → 땅 → 전기 순으로 올라갑니다. 테마는 자유롭게 고를 수 있고, 테마 안에서는 앞 스테이지를 깨야 다음이 열립니다.
- 그 위에 심화 테마 「심연의 땅」 5개(각 7 스테이지)가 더 있어 전체는 70 스테이지입니다. 심화에서는 몬스터가 2~3마리 나오고 속성이 서로 다릅니다.
- 몬스터가 여러 마리일 때는 몬스터 줄을 눌러 먼저 때릴 대상을 고릅니다. 고르는 데는 턴을 쓰지 않습니다. 약점은 고른 몬스터 기준으로 적용되고, 쓰러뜨리고 남은 데미지는 다음 몬스터로 넘어갑니다.
- 몬스터마다 공격 주기가 따로 있고, 모두 쓰러뜨려야 클리어입니다.
- 스테이지를 깨면 코인을 받습니다. 어려운 스테이지일수록 많이 받고, 처음 깰 때는 2배입니다.

### 뽑기와 아이템

- 메인 메뉴의 뽑기는 1회 60 코인입니다. 10회 뽑기도 있습니다.
- 아이템은 200종입니다. 등급별 확률은 일반 50% · 고급 28% · 희귀 12% · 전설 10% 이고, 등급이 높을수록 능력치가 좋습니다.
- 검은 공격, 방패는 방어, 갑옷은 체력, 반지는 공격+체력, 부적은 방어+체력을 올립니다.
- 방어는 받는 피해를 깎지만, 몬스터 공격력의 40% 아래로는 내려가지 않습니다.
- 가방에서 5개까지 장착할 수 있습니다. 이미 가진 아이템이 또 나오면 코인으로 돌려받습니다.

### 데미지

| 조건 | 배수 |
| --- | --- |
| 3칸 | 칸당 10 |
| 4칸 | ×2 |
| 5칸 이상 | ×3 |
| 두 줄이 교차 | 교차한 두 줄 ×2 |
| 연쇄(떨어져서 또 맞음) | 연쇄마다 +50% |
| 몬스터 약점 속성 | ×1.5 |

속성 상성: 물 › 불 › 나무 › 땅 › 전기 › 물

## 그 밖에

- 코인·클리어 진행·아이템·장착은 컴퓨터에 자동 저장되어 세션이 바뀌어도 남습니다.
- Claude 의 작업이 끝나면 알림이 뜹니다.

## 개발

```bash
claude plugin validate .   # 매니페스트·타입 검사
claude plugin test .       # 규칙 테스트
claude --plugin-dir .      # 폴더에서 바로 실행
```
