# 돌 맞추기 (stone-clash)

Claude Code 가 작업하는 동안 채팅 옆 패널에서 하는 5속성 돌 맞추기 턴제 퍼즐입니다. Claude Code 의 mod(플러그인)로 동작합니다.

## 설치

터미널에서 연 Claude Code 세션의 프롬프트에 입력합니다.

```
/plugin install stone-clash --marketplace moonjh9392/claude-mod-stone-clash
```

셸에서 설치하려면:

```bash
claude plugin install stone-clash --marketplace moonjh9392/claude-mod-stone-clash
```

마켓플레이스 추가를 묻는 질문에 `y` 로 답하고 설치 범위를 고르면 됩니다. mod 를 지원하는 Claude Code 버전이 필요합니다.

## 실행

- 세션을 시작하면 패널이 열립니다. 터미널 폭이 좁으면 자동으로 열리지 않으니 `/stone-clash` 를 입력하세요.
- 패널은 터미널 세션에서 확인했습니다. 데스크톱 앱 세션에서는 패널이 뜨지 않을 수 있습니다.

## 규칙

- 6×6 판에 5속성 돌(물🔵 불🔴 땅🟤 나무🟢 전기🟡)이 무작위로 깔립니다.
- 돌 하나를 누르고 바로 옆(상하좌우) 돌을 누르면 자리가 바뀝니다. 줄이 맞춰지지 않는 교환은 되돌아가고 턴을 쓰지 않습니다.
- 가로·세로는 3칸 이상, 대각선은 4칸 이상 같은 돌이 이어지면 사라지고 몬스터에게 데미지가 들어갑니다.
- 몬스터 체력이 0 이 되면 다음 스테이지로 넘어가고 내 체력이 20 회복됩니다.
- 몬스터는 2~4턴마다 공격합니다. 돌을 한 번 맞출 때마다 공격이 한 턴 가까워집니다.
- 내 체력(100)이 0 이 되면 쓰러지고 스테이지 1부터 다시 시작합니다.

### 데미지

| 조건 | 배수 |
| --- | --- |
| 3칸 | 칸당 10 |
| 4칸 | ×2 |
| 5칸 이상 | ×3 |
| 두 줄이 교차 | 교차한 두 줄 ×2 |
| 연쇄(떨어져서 또 맞음) | 연쇄마다 +50% |
| 몬스터 약점 속성 | ×1.5 |

속성 상성: 물 › 불 › 나무 › 땅 › 전기 › 물

## 그 밖에

- 최고 스테이지는 컴퓨터에 저장되어 세션이 바뀌어도 남습니다.
- Claude 의 작업이 끝나면 알림이 뜹니다.

## 개발

```bash
claude plugin validate .   # 매니페스트·타입 검사
claude plugin test .       # 규칙 테스트
claude --plugin-dir .      # 폴더에서 바로 실행
```
